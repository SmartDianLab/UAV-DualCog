# Anonymous Reviewer Examples

These are curated examples, not the full benchmark release. Each of the 21 scenes has two landmarks, four image tasks per landmark, and (for UAV-DualCog-V1) one paired behavior/visibility video trajectory per landmark.

Complete released landmark-list metadata and per-scene reviewed landmark records are included. Media for non-example landmarks are intentionally omitted. Image pixels are downsampled without changing normalized BBoxes; videos are H.264 720p compressed copies of the original trajectories.

See `index.json` for selected landmark IDs, manifest paths, and scene coverage. Paths inside sample manifests are relative to the repository root. The licensed GauUscene inputs and full AirSim scene assets are not redistributed.
