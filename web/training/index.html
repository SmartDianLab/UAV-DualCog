Training & Optimization

Two-Stage SFT & GRPO Optimization Probe: Hyperparameters, Rewards, and Curves

Beyond evaluation, we examine whether UAV-DualCog can serve as effective supervision to bridge the semantic-evidence and agent-world dual-cognition gaps. We construct UAV-DualCog-Train from six scenes strictly disjoint from the evaluation benchmark (11,232 samples, 234 landmarks) and train an edge-deployable base model (Qwen3.5-4B) using a two-stage alignment pipeline: Multimodal Supervised Fine-Tuning (SFT) followed by Joint Group Relative Policy Optimization (GRPO).

Reward Formulation

Multi-Objective Composite Reward Contract

To examine whether UAV-DualCog can serve as effective supervision beyond evaluation, we construct UAV-DualCog-Train from six scenes disjoint from the test benchmark. It contains 11,232 image samples covering four tasks, two difficulty levels, 234 landmarks, and the identical answer-bounding box contract. Using Qwen3.5-4B as a deployment base model, multimodal SFT stabilizes structured outputs, followed by Joint Group Relative Policy Optimization (GRPO) balancing format, answer correctness, and GIoU rewards. During GRPO exploration, each candidate response ŷ is scored by a composite reward function balancing syntactic formatting, semantic accuracy, and geometric spatial grounding:

R(ŷ) = wformat · Rformat(ŷ) + wanswer · Ranswer(ŷ, a*) + wbbox · Rbbox(ŷ, B*)
  • Rformat ∈ {0, 1}: Rule-based format validator verifying strict JSON serialization, valid answer_option_id in {A, B, C, D}, and normalized bounding box array bbox_xyxy_norm = [x1, y1, x2, y2] satisfying 0 ≤ x1 < x2 ≤ 1 and 0 ≤ y1 < y2 ≤ 1.
  • Ranswer ∈ {0, 1}: Discrete 0/1 indicator testing whether the predicted option matches ground truth a*.
  • Rbbox = GIoU(B̂, B*) ∈ [-1, 1]: Generalized Intersection over Union providing smooth gradient feedback even when predicted and ground-truth boxes do not overlap: GIoU(B̂, B*) = IoU(B̂, B*) - |C \ (B̂ ∪ B*)| / |C|, where C is the smallest enclosing bounding box.
