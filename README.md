# UAV-DualCog Supplementary Website

This repository hosts the supplementary website for **UAV-DualCog**, currently under peer review.

- Recovery website: https://anonymous.4open.science/w/UAV-DualCog-Recovery/
- Recovery code repository: https://anonymous.4open.science/r/UAV-DualCog-Code-Recovery/
- for-Replacement website: https://anonymous.4open.science/w/UAV-DualCog-for-Replacement/
- for-Replacement code repository: https://anonymous.4open.science/r/UAV-DualCog-Code-for-Replacement/

The website presents the benchmark design, construction pipeline, evaluation protocol, leaderboard, paired dual-cognition analysis, training details, a Sim-to-Real 3DGS image pilot, and usage instructions.
